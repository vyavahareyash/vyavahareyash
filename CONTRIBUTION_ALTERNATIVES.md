### Option 2: 3D Isometric Contribution Landscape (`github-profile-3d-contrib`)
*Extrudes GitHub commit history into an isometric 3D city-block landscape.*

<div align="center">
  <img src="https://raw.githubusercontent.com/yoshi389111/github-profile-3d-contrib/main/docs/demo/profile-green-animate.svg" width="85%" alt="3D Isometric Landscape" />
</div>

**How it works:**
- A GitHub Action runs daily and generates `profile-3d-contrib/profile-night-rainbow.svg` directly into an `output` branch.
